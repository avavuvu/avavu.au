Live coding is the practice of writing code in a live performance setting. I have been involved with live coding in two forms, creating music with [Strudel](https://strudel.cc/), and creating visuals with [Hydra](https://hydra.ojack.xyz/).

I first became involved with live coding during my time at [[Code Jam]], a six-week course at [[WP:Melbourne Electronic Sound Studio|MESS]]. It culminated in a [[codejam|performance at Make It Up Club]] at Bar Open on 31 March 2026. I feel very lucky to have been accepted into Code Jam, because the people I met were so lovely and talented.

Since Code Jam officially ended, there has been some effort to create a larger community of live coders in Melbourne. There have been a few meet-ups as a group called [[Live coders Naarm]]. I have also done another Live coding performance with my friend and fellow Code Jam-alum Hannah Ogawa.
